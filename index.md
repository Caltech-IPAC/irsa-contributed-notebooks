# IRSA Contributed Python Notebooks

These Python Jupyter notebooks demonstrate science use cases of data served by [Caltech/IPAC-IRSA](https://irsa.ipac.caltech.edu) (IRSA).
They are written and contributed to IRSA by mission scientists and others who use the data.
(For notebooks written and maintained by IRSA, see [IRSA Tutorial Notebooks](https://caltech-ipac.github.io/irsa-tutorials/).)

Each notebook includes instructions for installing the software it depends on, pinned to versions known to work.
Each notebook is checked to run end-to-end with that setup before it's published, but it's not regularly tested or maintained afterward.
